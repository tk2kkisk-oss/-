# ナレーション付きPPTX → アニメーション動画

PPTXに入っているナレーション音声とノート（台本）をそのまま使い、白×ロイヤルブルーのアニメーション動画を作る。
ナレーションが読み上げた言葉に合わせて要素が出てきて、読んでいる項目は枠で強調し、下には字幕を出す。
しくみは「1枚のHTML（1920×1080のステージ）を時刻 t で描き分け、Playwrightで1コマずつ撮ってffmpegでMP4にする」というもの。

## 全体の流れ

1. **下準備**：`scripts/prepare.py` で、音声の取り出し・台本と音声の時刻合わせ・プロジェクト一式の作成をまとめて行う
2. **シーンを書く**：`slides.md` を読み、`index.html` のシーンを1スライド＝1シーンで書き直す
3. **静止画で確認**：要所の静止画を撮り、はみ出しや重なりを直す（ここが品質を左右する）
4. **書き出し**：MP4を書き出して検証し、ユーザーに渡す

### 1. 下準備

```sh
python3 -I <skill>/scripts/prepare.py <input.pptx> <project_dir>
```

`project_dir` には次のものができる。

- `assets/audio/01.mp3…`：スライドの順番どおりに並べた音声。音声がないスライドは6秒の無音にする（`--silent-sec` で変更可）
- `timing.js`：台本の何文字目が何秒目に読まれるかの対応表。句読点を音声の無音区間に割り当てて作る
- `slides.md`：スライド本文・台本・尺・画像の一覧
- `index.html`：テンプレート。部品とアニメーションエンジンが入っている
- `tools/render.cjs`：書き出し用のスクリプト
- `assets/fonts/`：Zen Kaku Gothic New

ユーザーがプロジェクトをリポジトリに置きたい場合は、リポジトリ内の `video/` などを `project_dir` にする。
`assets/media/` にはスライドの画像が入る。ただしPowerPointの音声アイコン（256px前後の小さい画像）も混ざるので、使うのはQRコードや写真など意味のある画像だけにする。

### 2. シーンを書く

最初に `index.html` を読む。テンプレートのシーンは、16枚の認知症ケア研修を動画にした実例になっている。
そのまま使える部品が揃っているので、CSSは残し、`<section class="scene">` だけをスライドの枚数ぶん書き直す。
エンジンはシーンの数と `timing.js` のスライド数が合わないとエラーで止まる。

ここで大事なのは、**元のスライドを写すのではなく、ナレーションの流れに沿って見せること**。
1枚に情報が多いスライドは、`.pg` を2〜3枚に分けて順番に見せる。たとえば「図 → 具体例 → 結論のメッセージ」のように切り替える。
ユーザーが見本のHTMLや配色を指定した場合は、`:root` の色とフォントを差し替え、見本の動き方（下から出る、弾む、線を引く、取り消し線など）をまねる。

#### タイミングの書き方（要素ごとにdata属性を付ける）

| 属性 | 意味 |
|---|---|
| `data-in="台本の言葉"` | その言葉が読まれる瞬間（約0.1秒前）に登場する。数字だけなら、シーン開始からの秒数として扱う |
| `data-off="0.4"` | 登場時刻をずらす秒数。同じきっかけで複数の要素を順番に出すときに使う |
| `data-fx` | 登場の動き。`rise`（標準・下から）／`pop`（弾む）／`fade`／`grow`（横に伸びる。下線や取り消し線向き）／`growy`（縦に伸びる。段や棒向き）。`data-dur` で長さを変えられる |
| `data-out="言葉"` | その言葉で退場する。`.pg` に付けて、ページの切り替えに使う |
| `data-hl="言葉"` `data-hl-end="言葉"` | その間だけ、青い枠と影で強調する。`class="hl"` と一緒に使う |
| `data-loop` | `blink`／`shake`／`pulse`／`flicker`（炎）のくり返し。`data-loop-at` で開始のきっかけを指定する |

- **言葉は台本からそのまま写す**。`slides.md` の台本から、ひと続きの文字列を抜き出して使う。ナレーションは読み上げ用の表記（例：「ビーピーエスディー」）なので、画面の表記と違うことがある。見つからない言葉があると、ページがエラーを出して止まる。
- **最初に出てくる場所が使われる**。同じ言葉が台本に2回以上出てくるときは、前後を含めた長めの文字列にする。
- **字幕は句点ごとに自動で出る**。読み上げ用の表記を画面用に直したいときは、エンジンの `caps` の置き換え処理（`replace(/ビーピーエスディー/g,'BPSD')` のところ）に追加する。

#### レイアウトの注意（実際につまずいた点）

- **使える高さ**：ステージは1920×1080。下の約8cqwは字幕帯なので、本文に使えるのは見出しの下からおよそ600pxしかない。文字は1.5cqw（約29px）より小さくしない。入らないときは、文を短くするかページを分ける。
- **`transform` は使わない**：JSが登場の動きで `transform` を上書きするため、`data-in` を付けた要素に `transform:translateX(-50%)` などを書くと位置がずれる。位置の調整は `translate:` プロパティや `left/top` で書く。
- **親子の透明度は掛け算になる**：親と子の両方に `data-in` を付けてよい。ただし `.dim` のような「CSSの opacity で薄くする」書き方は、JSが上書きして効かない。薄くしたいときは色（`color-mix`）で表す。
- **SVGの中身を動かすとき**：`transform-box:fill-box` が効くので、拡大縮小はその図形の中心が基準になる。炎のように下を基準にしたいときは `transform-origin:50% 100%` を書く。

### 3. 静止画で確認する（必ずやる）

```sh
NODE_PATH=$(npm root -g) node tools/render.cjs --still 12.5,40.2,77.8
```

- **確認する時刻**：各シーンの終わりの約1.3秒前（全要素が出そろった状態）と、ページを切り替えるシーンの途中。シーンの開始時刻は「0.6＋音声の長さ＋1.0」を順に足していけば求まる。
- **見方**：PILで4枚ずつ縮小して並べた一覧画像を作り、まとめて見る。
- **よくある崩れ**：中身が多すぎて見出しに重なる／字幕帯の下に隠れる／見出しが2行になる／余計な位置で改行される。CSSの文字サイズを詰めるか文を短くして、崩れがなくなるまで撮り直す。
- **Playwrightが見つからない場合**：`npm root -g` で見つからなければ `find / -name playwright -maxdepth 6 -path '*node_modules*'` で探す。ブラウザは事前に入っているものを使い、`playwright install` はしない。

### 4. 書き出しと受け渡し

```sh
NODE_PATH=... node tools/render.cjs out.mp4 --workers 4   # バックグラウンドで実行する
```

- **書き出し時間**：10分の動画で十数分かかる（30fps、4並列）。画面が変わらないコマは撮影を省略するので、静止している時間が長いほど速い。終わるまで待ち、待っている間に完了の監視を仕掛けておく。
- **ナレーション**：シーンの長さに合わせた音声が `assets/narration.m4a` にでき、MP4に入る。この音声は、`index.html` をブラウザで開いてプレビュー再生するときにも使われる。
- **検証**：ffprobeで尺・解像度・音声トラックを確認する。何か所かのコマを抜き出して表示を、`volumedetect` で音が入っているかを見る。
- **受け渡し**：送れるファイルには上限（例：30MB）がある。超える場合は `-crf 26 -preset slow -c:a copy` で再エンコードした軽量版を送り、高画質版はリポジトリやプロジェクトに残す。
- **ユーザーへの説明**：短く伝える。動画の尺と解像度／元スライドから変えた見せ方（ページを分けたこと、文言を短くしたこと）／使う前に人が確認すべき点（短くした文言、QRコードが読み取れるか など）／直し方（`index.html` を開いてプレビューし、`data-in` を変えて書き出し直す）。

## 補足

- **ナレーションを差し替えたとき**：`prepare.py` をもう一度実行するだけでよい。`index.html` がすでにある場合は上書きしない。
- **ノートが空・音声がないスライド**：字幕は出ない。`data-in` には秒数を書く。
- **台本と音声が大きくずれる場合**（台本と違うことを話しているなど）：秒数を直接書いて対応する。
